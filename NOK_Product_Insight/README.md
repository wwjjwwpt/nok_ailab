# NOK 产品经营分析

一个面向销售、采购和管理人员的 Windows 桌面分析工具。用户导入 Excel 后，程序会自动识别产品、销量、库存、采购和客户字段，计算经营指标并生成产品分层、风险预警和可导出的分析报告。

## 已实现功能

- 自动识别 Excel 中最可能的数据工作表和表头行；
- 自动识别不同排列顺序的字段；
- 自动识别 `YYYY年M月销售数量`、`YYYY-MM销售数量` 等月份列；
- 支持 `.xlsx`、`.xlsm`、`.xls` 和 `.csv`；
- 计算15项经营指标；
- 自动生成 ABC 分类和产品经营分层；
- 自动识别供货风险、库存积压、销量衰退和历史断货；
- 总览仪表盘、产品清单、产品详情、风险预警、指标说明；
- 产品清单支持经营核心、销售趋势、库存采购、客户风险、全部指标五种视图；
- 搜索、产品分层筛选、高优先级筛选和表格排序；
- 双击产品进入完整经营画像，查看月度销量趋势和全部指标的业务解释；
- 库存水位轨：比较当前可销月数和目标月数；
- 导出包含管理摘要、产品指标、月度销量、风险预警、原始数据、字段映射、指标说明和数据质量的 Excel 报告；
- 提供 Windows EXE 一键打包脚本。

## 指标

1. 销售贡献率
2. ABC分类
3. 近3个月增长率
4. 需求波动系数
5. 合计可销月数
6. 库存覆盖缺口
7. 销售库存错配指数
8. 缺口参考销售额
9. 超储参考销售额
10. 理论补货量
11. 建议采购量
12. 客户复购频次
13. 断货率
14. 采购覆盖月数
15. 经营优先分

程序会进一步把产品分为：

- 明星守供品
- 增长培育品
- 高库存促销品
- 衰退观察品
- 补货关注品
- 常规经营品
- 数据不足

## Excel 最低要求

至少需要：

- `品号`或`品名`；
- 多个月份的销售数量，或者`月平均销售数量`。

推荐提供：

- 参考售价；
- 月平均销售金额；
- 总可用量；
- 合计未完成；
- 合计可销月数；
- 目标可销月数；
- 最低补货量；
- 销售占比和库存占比；
- 购买客户数和购买次数；
- 当月采购数量；
- 断货次数。

字段不要求固定列顺序。常见别名如“产品编号”“物料编号”“产品名称”“月均销量”“目标库存月数”等也可以自动识别。

## 本地运行

需要 Python 3.11。

### Windows

双击：

```text
run_windows.bat
```

第一次运行会创建虚拟环境并安装依赖。

### 命令行

```bash
python -m venv .venv

# Windows
.venv\Scripts\activate

# macOS / Linux
source .venv/bin/activate

pip install -r requirements.txt
python app.py
```

### macOS测试版

项目提供原生 Apple Silicon（M系列芯片）应用打包配置。执行：

```bash
chmod +x build_macos.sh
./build_macos.sh
```

生成文件：

```text
dist/NOK 产品经营分析.app
```

也可以双击 `run_macos.command`，直接以Python方式运行。

如果首次打开时macOS提示无法验证开发者：

1. 在访达中按住 Control 点击应用；
2. 选择“打开”；
3. 在确认窗口中再次选择“打开”。

这是因为本地测试包没有使用Apple开发者证书签名，不影响分析功能。

启动时直接加载文件：

```bash
python app.py "D:\data\采购分析.xlsx"
```

打包后的程序也可以使用 `--open` 参数启动并自动加载文件，便于测试或集成。

无界面分析并导出：

```bash
python app.py --analyze "D:\data\采购分析.xlsx" --output "D:\data\经营分析结果.xlsx"
```

## 生成 Windows EXE

由于 PyInstaller 不能在 macOS 上直接生成可靠的 Windows 可执行文件，必须在 Windows 10/11 上执行最后一次打包。

1. 安装 64 位 Python 3.11；
2. 把整个 `NOK_Product_Insight` 文件夹复制到 Windows；
3. 如果只需要免安装 EXE，双击 `build_windows.bat`；
4. 如果需要正式安装向导，双击 `build_windows_installer.bat`；
5. 安装版脚本会在缺少 Inno Setup 6 时提示自动安装；
6. 等待依赖安装和打包完成。

正式安装版生成于：

```text
release\NOK_Product_Insight_Setup_v1.1.0_x64.exe
```

免安装版生成于：

```text
release\NOK_Product_Insight_Portable_v1.1.0_x64.exe
```

安装版提供桌面快捷方式、开始菜单和卸载程序。详细说明见 `WINDOWS_安装版说明.md`。

旧的单独 EXE 构建流程仍会生成：

```text
dist\NOK_Product_Insight.exe
```

EXE 是单文件程序，目标电脑不需要另行安装 Python。

## 口径说明

- 金额类库存指标按参考售价计算，是“参考销售价值”，不等于采购成本、现金占用或毛利。
- 如果 Excel 已有“合计可销月数”，程序优先使用原值；否则使用“总可用量＋合计未完成”推导。
- 如果 Excel 已有目标月数，程序优先使用每个产品自己的目标；顶部“默认目标月数”仅用于补齐缺失值。
- 近3个月趋势需要至少6个月销量数据。
- 高库存默认定义为“合计可销月数 ≥ 目标月数×2”，可在界面顶部调整。
