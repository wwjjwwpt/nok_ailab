# NOK AI Lab 项目概述

## 项目简介

NOK AI Lab 是一个企业级 AI 平台，采用前后端分离架构，部署在阿里云上。

## 技术栈

### 后端
- **框架**: FastAPI
- **数据库**: PostgreSQL 16+ (阿里云 RDS)
- **缓存**: Redis
- **ORM**: SQLAlchemy
- **认证**: JWT

### 前端
- **框架**: Next.js 15
- **UI 库**: React + TypeScript
- **状态管理**: 待定

### 部署
- **容器**: Docker + Docker Compose
- **云平台**: 阿里云
- **数据库**: 阿里云 RDS PostgreSQL

## 核心功能模块

1. **用户认证模块** - JWT 登录、Token 刷新
2. **权限管理模块** - RBAC + 数据权限混合模型
3. **菜单管理模块** - 动态导航、角色可见性控制
4. **部门管理模块** - 组织架构管理
5. **日志管理模块** - 登录日志、操作日志

## 项目结构

```
nok_ailab/
├── backend/              # 后端代码
│   ├── app/
│   │   ├── api/         # API 路由
│   │   ├── core/        # 核心配置
│   │   ├── models/      # 数据库模型
│   │   └── schemas/     # Pydantic Schema
│   ├── scripts/         # 脚本工具
│   └── .env             # 环境配置
├── frontend/            # 前端代码
├── docs/                # 项目文档
└── docker-compose.yml   # Docker 编排
```
