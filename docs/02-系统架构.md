## 权限模型设计

### 混合权限模型

本系统采用 **RBAC + 直接授权** 的混合权限模型：

```
用户 ──→ 角色 ──→ 权限 (菜单/功能/数据)
  │
  └──────→ 直接权限 (特殊授权)
```

### 权限类型

| 权限类型 | 说明 | 控制粒度 |
|---------|------|---------|
| **菜单权限** | 控制用户可见的导航菜单 | 页面级 |
| **功能权限** | 控制按钮、API 接口访问 | 操作级 |
| **数据权限** | 控制数据访问范围 | 数据级 |

### 数据权限范围

| 范围 | 说明 |
|------|------|
| 全部数据 | 可访问系统全部数据 |
| 本部门及子部门 | 可访问本部门及下级部门数据 |
| 本部门 | 仅访问本部门数据 |
| 仅本人 | 仅访问本人创建的数据 |
| 自定义 | 自定义数据范围 |

## 认证流程

### JWT Token 机制

```
登录请求
   │
   ▼
验证用户名密码
   │
   ▼
生成 Access Token + Refresh Token
   │
   ▼
返回给客户端
   │
   ▼
客户端存储 (localStorage/cookie)
   │
   ▼
后续请求携带 Access Token
   │
   ▼
Token 过期？──是──→ 使用 Refresh Token 刷新
   │                    │
   否                  过期？──是──→ 重新登录
   │                    │
   ▼                    否
返回受保护资源              ▼
                    生成新 Token
```
