# 数据库设计

## 表列表

系统共包含 14 张核心表：

| 表名 | 说明 |
|------|------|
| `users` | 用户表 |
| `roles` | 角色表 |
| `menus` | 菜单表 |
| `permissions` | 功能权限表 |
| `data_scopes` | 数据权限规则表 |
| `departments` | 部门表 |
| `user_roles` | 用户 - 角色关联表 |
| `role_menus` | 角色 - 菜单关联表 |
| `role_permissions` | 角色 - 权限关联表 |
| `role_data_scopes` | 角色 - 数据权限关联表 |
| `user_permissions` | 用户直接权限表 |
| `user_data_scopes` | 用户直接数据权限表 |
| `login_logs` | 登录日志表 |
| `operation_logs` | 操作日志表 |

## 通用字段规范

所有表都包含以下审计字段：

| 字段 | 类型 | 说明 |
|------|------|------|
| `created_at` | TIMESTAMP | 创建时间 |
| `updated_at` | TIMESTAMP | 更新时间 |
| `status` | SMALLINT | 状态 (1-正常，0-禁用) |
| `deleted_at` | TIMESTAMP | 删除时间 (软删除) |

## 核心表结构

### users - 用户表

```sql
CREATE TABLE users (
    id BIGSERIAL PRIMARY KEY,
    username VARCHAR(50) UNIQUE NOT NULL,
    password VARCHAR(255) NOT NULL,
    email VARCHAR(100) UNIQUE,
    phone VARCHAR(20) UNIQUE,
    nickname VARCHAR(50),
    dept_id BIGINT REFERENCES departments(id),
    avatar VARCHAR(500),
    status SMALLINT DEFAULT 1,
    email_verified BOOLEAN DEFAULT FALSE,
    phone_verified BOOLEAN DEFAULT FALSE,
    last_login_time TIMESTAMP,
    last_login_ip VARCHAR(50),
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    deleted_at TIMESTAMP
);
```

### roles - 角色表

```sql
CREATE TABLE roles (
    id BIGSERIAL PRIMARY KEY,
    name VARCHAR(50) NOT NULL,
    code VARCHAR(50) UNIQUE NOT NULL,
    description VARCHAR(255),
    is_system BOOLEAN DEFAULT FALSE,
    status SMALLINT DEFAULT 1,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    deleted_at TIMESTAMP
);
```

### menus - 菜单表

```sql
CREATE TABLE menus (
    id BIGSERIAL PRIMARY KEY,
    name VARCHAR(50) NOT NULL,
    code VARCHAR(50) UNIQUE NOT NULL,
    parent_id BIGINT DEFAULT 0,
    path VARCHAR(200),
    component VARCHAR(200),
    icon VARCHAR(50),
    type SMALLINT,
    sort_order SMALLINT DEFAULT 0,
    visible BOOLEAN DEFAULT TRUE,
    permission VARCHAR(100),
    status SMALLINT DEFAULT 1,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    deleted_at TIMESTAMP
);
```

### permissions - 功能权限表

```sql
CREATE TABLE permissions (
    id BIGSERIAL PRIMARY KEY,
    name VARCHAR(50) NOT NULL,
    code VARCHAR(100) UNIQUE NOT NULL,
    menu_id BIGINT REFERENCES menus(id),
    type VARCHAR(20),
    api_method VARCHAR(10),
    api_path VARCHAR(200),
    description VARCHAR(255),
    status SMALLINT DEFAULT 1,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    deleted_at TIMESTAMP
);
```

### data_scopes - 数据权限规则表

```sql
CREATE TABLE data_scopes (
    id BIGSERIAL PRIMARY KEY,
    name VARCHAR(50) NOT NULL,
    code VARCHAR(50) UNIQUE NOT NULL,
    scope_type SMALLINT NOT NULL,
    scope_config JSONB,
    description VARCHAR(255),
    status SMALLINT DEFAULT 1,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    deleted_at TIMESTAMP
);
```

## 关联关系

### 用户 - 角色关系
- 多对多，通过 `user_roles` 表关联

### 角色 - 菜单关系
- 多对多，通过 `role_menus` 表关联

### 角色 - 权限关系
- 多对多，通过 `role_permissions` 表关联

### 角色 - 数据权限关系
- 多对多，通过 `role_data_scopes` 表关联

## 索引设计

主要索引：
- 用户表：username, email, phone, dept_id, status
- 角色表：code, status
- 菜单表：parent_id, code, status
- 权限表：code, menu_id, status
- 关联表：各外键字段

## 初始化数据

系统初始化后包含：
- 1 个默认管理员账号 (admin/admin123)
- 2 个系统角色 (超级管理员、普通用户)
- 8 个系统菜单
- 28 个功能权限
- 4 个数据权限规则
- 1 个默认部门
