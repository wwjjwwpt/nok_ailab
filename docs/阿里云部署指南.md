# 阿里云部署指南

## 前置准备

### 1. 阿里云账号注册
- 访问 https://www.aliyun.com 注册账号
- 完成实名认证

### 2. 开通服务
需要开通以下服务：
- **ECS 云服务器** - 运行应用
- **RDS PostgreSQL** - 数据库
- **Redis 云数据库** - 缓存 (可选，可用 ECS 自建)

---

## 一、数据库配置 (RDS PostgreSQL)

### 1.1 创建 RDS 实例
1. 登录阿里云控制台
2. 进入 RDS 产品页：https://rds.console.aliyun.com
3. 点击"创建实例"
4. 配置选择：
   - 地域：选择离用户最近的地域 (如：华东 1-杭州)
   - 引擎版本：PostgreSQL 16
   - 系列：高可用版 (生产建议)
   - 规格：2 核 4GB 起步
   - 存储：50GB 起步
   - 网络类型：VPC
   - 可用区：默认

### 1.2 设置白名单
1. 进入实例详情 → 白名单设置
2. 添加白名单：
   - 经典网络白名单：添加你的 ECS 内网 IP
   - 或添加 `0.0.0.0/0` (不推荐，仅测试)

### 1.3 创建数据库
1. 进入实例详情 → 数据库管理
2. 创建数据库：
   - 数据库名：`nok_ailab`
   - 字符集：`UTF8`
   -  Owner: postgres

### 1.4 获取连接信息
记录以下信息 (用于配置 `.env` 文件)：
- 内网地址：如 `pgm-xxx.mysql.rds.aliyuncs.com`
- 端口：`5432`
- 用户名：`postgres`
- 密码：创建实例时设置的密码

## 二、Redis 配置

### 2.1 使用阿里云 Redis (推荐)
1. 登录阿里云控制台
2. 进入 Redis 产品页：https://kvstore.console.aliyun.com
3. 创建实例
   - 地域：与 RDS/ECS 相同
   - 架构：标准版
   - 规格：256MB 起步
4. 设置白名单 (添加 ECS IP)
5. 获取连接信息

### 2.2 或 ECS 自建 Redis
```bash
# ECS 上安装 Redis
sudo apt update
sudo apt install -y redis-server
sudo systemctl start redis
sudo systemctl enable redis
```

## 三、ECS 服务器配置

### 3.1 创建 ECS 实例
1. 登录阿里云控制台
2. 进入 ECS 产品页：https://ecs.console.aliyun.com
3. 创建实例：
   - 地域：与 RDS 相同
   - 镜像：Ubuntu 22.04 LTS
   - 规格：2 核 4GB 起步
   - 系统盘：40GB ESSD
   - 网络：VPC (与 RDS 同 VPC)
   - 安全组：开放 80/443/22 端口

### 3.2 连接 ECS
```bash
# 使用 SSH 连接
ssh root@<ECS 公网 IP>
```

### 3.3 安装基础软件
```bash
# 更新系统
apt update && apt upgrade -y

# 安装 Docker
curl -fsSL https://get.docker.com | bash
systemctl start docker
systemctl enable docker

# 安装 Docker Compose
apt install -y docker-compose

# 安装 Nginx
apt install -y nginx
```

### 3.4 部署应用

```bash
# 创建部署目录
mkdir -p /opt/nok_ailab
cd /opt/nok_ailab

# 上传代码 (方式 1：git clone)
git clone <your-repo-url> .

# 上传代码 (方式 2：本地打包上传)
# 本地执行：tar czf nok_ailab.tar.gz backend frontend docker-compose.yml
# 上传：scp nok_ailab.tar.gz root@ecs-ip:/opt/nok_ailab/
# 解压：tar xzf nok_ailab.tar.gz
```

### 3.5 配置环境变量

创建后端配置 `.env`：
```bash
cd /opt/nok_ailab/backend
cat > .env << EOF
# 应用配置
APP_NAME=企业 AI 平台
APP_VERSION=1.0.0
DEBUG=False
API_PREFIX=/api/v1

# 服务器配置
HOST=0.0.0.0
PORT=8000

# 阿里云 RDS 数据库
DB_HOST=<RDS 内网地址>
DB_PORT=5432
DB_NAME=nok_ailab
DB_USER=postgres
DB_PASSWORD=<RDS 密码>
DB_POOL_SIZE=10
DB_MAX_OVERFLOW=20

# Redis 配置
REDIS_HOST=<Redis 地址>
REDIS_PORT=6379
REDIS_DB=0
REDIS_PASSWORD=<Redis 密码>

# JWT 配置 (务必修改为强密钥!)
JWT_SECRET_KEY=<生成 32 位以上随机字符串>
JWT_ALGORITHM=HS256
JWT_ACCESS_TOKEN_EXPIRE_MINUTES=60
JWT_REFRESH_TOKEN_EXPIRE_DAYS=7

BCRYPT_ROUNDS=12

# CORS 配置
CORS_ORIGINS=["https://your-domain.com"]

LOG_LEVEL=INFO
LOG_FILE=logs/app.log
EOF
```

创建前端配置 `.env.local`：
```bash
cd /opt/nok_ailab/frontend
cat > .env.local << EOF
NEXT_PUBLIC_API_BASE_URL=https://your-domain.com
EOF
```

### 3.6 启动服务

```bash
cd /opt/nok_ailab

# 构建并启动
docker-compose build
docker-compose up -d

# 查看日志
docker-compose logs -f backend
docker-compose logs -f frontend
```

### 3.7 配置 Nginx

```bash
# 复制 Nginx 配置
cp /opt/nok_ailab/infra/nginx/nginx.conf /etc/nginx/sites-available/nok_ailab

# 编辑配置 (修改域名和 SSL 证书路径)
vim /etc/nginx/sites-available/nok_ailab

# 启用配置
ln -s /etc/nginx/sites-available/nok_ailab /etc/nginx/sites-enabled/

# 测试配置
nginx -t

# 重启 Nginx
systemctl restart nginx
```

### 3.8 配置 SSL 证书

```bash
# 创建证书目录
mkdir -p /etc/nginx/ssl

# 上传证书文件 (从阿里云 SSL 控制台下载)
# 上传到 /etc/nginx/ssl/ 目录
```

## 五、运维管理

### 5.1 查看日志
```bash
# 应用日志
docker-compose logs -f backend

# Nginx 日志
tail -f /var/log/nginx/nok_ailab_access.log
tail -f /var/log/nginx/nok_ailab_error.log
```

### 5.2 备份数据库
```bash
# 导出数据库
pg_dump -h <RDS 地址> -U postgres -d nok_ailab > backup_$(date +%Y%m%d).sql

# 导入数据库
psql -h <RDS 地址> -U postgres -d nok_ailab < backup.sql
```

### 5.3 更新应用
```bash
cd /opt/nok_ailab

# 拉取最新代码
git pull

# 重新构建并重启
docker-compose build
docker-compose up -d
```

## 六、安全加固

### 6.1 安全组配置
- 仅开放必要端口：80/443
- SSH 端口 22 限制特定 IP 访问

### 6.2 数据库安全
- 使用强密码
- 定期备份
- 开启 SQL 审计

### 6.3 应用安全
- 使用 HTTPS
- 定期更新依赖
- 配置 JWT 密钥为强随机字符串

## 常见问题

### Q1: 后端连接数据库失败
检查 RDS 白名单是否包含 ECS IP

### Q2: 前端访问后端 404
检查 Nginx 反向代理配置

### Q3: Token 刷新失败
检查 Redis 连接是否正常

### Q4: 跨域问题
检查 CORS_ORIGINS 配置是否正确
